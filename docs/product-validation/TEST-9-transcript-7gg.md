# Test 9 — Pilota 7gg (transcript / daily diary)

One diary block per client per day, days 1–6 (day 7 is the feedback form).
Written the same day, in the client's own words. **Verbatim is preserved:
roughness is signal.** Editing a client's words is fabrication (§honesty).

## Diary block (copy per client per day)

```markdown
### Day __ — client ____ (role ____) — date ____

- Video produced (title/brief): ____
- Render evidence (artifact + receipt path): ____
- What took the longest today: ____
- What broke (if anything) and how it was recovered: ____
- Verbatim — one sentence in the client's own words: "____"
- Manual touches today (count): ____
- Minutes spent per video today: ____
```

## Rules

- No paraphrase. Typos, tone and fragments stay as spoken or typed.
- A day with no production is still logged: `no production — reason: ____`.
- If the assistant rewrites a sentence, the original is kept and the rewrite is
  marked `paraphrase:` after it.

## Aggregate (`transcripts/aggregate.md`, written at pilot close)

The aggregate is produced from the diaries + day-7 forms:

```markdown
# Test 9 — transcripts aggregate

- Clients completed: ____ (>= 5 required)
- Median Q1 (better than previous): ____   -> CAT-9 line 1: >= +1
- Median Q2 (would use again): ____        -> CAT-9 line 2: >= +1
- Median Q3 (min/video saved): ____        -> CAT-9 line 3: >= 30
- Per-role medians (founder/PM/designer/operator): ____
- Quotes kept verbatim: yes/no
- Missing answers excluded from medians (count): ____
```

## §honesty cert (PARTIAL)

- Diary entries are real client sessions; nothing in this file is seeded or
  synthetic.
- Roughness is signal: smoothing a quote is a §honesty violation, even with
  the client's consent.
