# docs/migrations/application-infrastructure-imports-allowlist.txt
# ─────────────────────────────────────────────────────────────────────────────
# Per-file allowlist for Wave 19 PR4 (application → infrastructure) hard
# gate. Mirrors the canonical shape of
# docs/migrations/api-infrastructure-imports-allowlist.txt (Wave 14
# precedent).
#
# HOW THIS FILE WORKS
# ────────────────────
# scripts/archcheck/main.go::checkApplicationToInfrastructure emits a
# per-import edge list under Edges["application_to_infrastructure"] (one
# Edge per import line, {src_file, import, type="platform", in_ports}).
# The distinct src_file set from that edge list is compared (subtractSet)
# against this allowlist. Any src_file present in actual imports but NOT
# here is a regression; any allowlist entry that no longer matches an
# actual is a stale grandfathered entry. Both directions fail the gate
# (the gate is symmetric, like `checkAPIInfrastructureImports`).
#
# FORMAT
# ──────
# One repo-root-relative path per active line (forward-slash). Lines that
# start with `#` are comments and ignored by `loadAllowlist`. Entries
# are sorted + deduped + forward-slash normalized (matches
# `filepath.ToSlash` in scripts/archcheck/main.go).
#
# POLICY
# ──────
# Adding a NEW entry REQUIRES operator review (no solo adds). Removing
# an entry is safe — the gate will surface the still-present actual
# import as a `new application_to_infrastructure import not in
# allowlist: <file>` violation for action.
#
# CURRENT STATE — Wave 19 PR4 seed baseline (2026-06-26)
# ─────────────────────────────────────────────────────────────────────────────
# Baseline seeded from the canonical Go-side scan via `go run
# ./scripts/archcheck` and the Edges["application_to_infrastructure"]
# per-import graph. Distinct src_file set captured at seed time: see
# the entries below.
#
# Operators remove entries as files get cleaned (mirrors the Wave 14
# api-infrastructure pattern: each cleanup PR is a removal here, never
# a re-add). The fix path for any file in this allowlist: lift the
# concrete adapter behind a typed port declared in `<cap>/ports.go`
# (AGENTS.md Pattern 0), replace the direct import with the port,
# add the composition-root wiring in `internal/app/`.
