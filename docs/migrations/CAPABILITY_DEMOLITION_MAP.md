# Capability → Consumers Demolition Map (2026-09-09)

Generated by scanning every `internal/capabilities/*` package for external
importers (`grep -rl "PipelineGen/internal/capabilities/<c>[" internal/ cmd/
pkg/`, self-imports excluded). Purpose: plan phased demolition of
capabilities outside the operator's kept perimeter
(**Script generation, Info/Web research, TTS/voiceover, Rust media pipeline**).

Legend:
- **LIVE** — consumed by wiring/routes/other capabilities: keep.
- **ADMIN-ONLY** — consumed only by `cmd/admin` / `cmd/worker` tools: demolish
  together with the admin command that uses it, or keep if the admin tool stays.
- **DEMOLISH** — zero or near-zero real consumers: candidate for removal.
- **PULL-IN** — kept because a kept consumer imports it (not independently justified).

## Demolition phases (proposed order, each step: `go build ./...` + impacted package tests + `make verify-agent`)

### Phase 1 — dead-weight singles (safe, no kept consumer loses anything)
1. `multilingual` (104 KB) + `cmd/admin/internal/rendering/multilingual_*` (4 files) — its ONLY consumers.
2. `workerdoctor` (52 KB) + `cmd/worker/doctor_main.go` — its only consumer.
   - Check `cmd/worker/main.go` dispatch first; remove the doctor route only.

### Phase 2 — admin-only clusters (decide whether the admin tool stays)
3. `adminmedia` (24 KB) — consumers are only admin cmds (`soundeffects/*`,
   `render_short`) + `rustexec/admin_media.go`. If sound-effects admin tooling
   is dead for the kept perimeter, remove capability + admin cmds together.
4. `reconciliation` (180 KB) + `cmd/admin/reconcile` Qdrant reconcile adapters —
   NOTE: AGENTS.md keeps Qdrant for mediamemory/DR/audit; if DR reconcile stays,
   keep; otherwise remove `lifecycle_maintenance.go` hooks too.
5. `controlplane` (12 KB) — contract only implemented by
   `platform/sqlite/controlplane` + admin verify cmd. Remove together with
   `platform/sqlite/controlplane/` and `cmd/admin/.../control_plane_verify.go`.

### Phase 3 — pull-ins requiring rewiring (only if the host capability goes)
6. `brain` (112 KB) — only consumer is mediamemory resolver chain + 2 wiring
   files. Demolish only together with mediamemory resolver (mediamemory itself
   stays; its brain deps must be inlined or simplified first).
7. `projectionretention` — referenced by `build_process_qdrant.go` config +
   qdrant collection retention. Remove only if projection retention policy is
   dropped from config (config field `cfg.Qdrant.ProjectionRetention` must go too).
8. `semantic` (28 KB) — referenced by `lifecycle_scheduler.go`; verify the
   scheduled semantic job is actually used before removal.
