# Zero Legacy Tickets

Questa directory contiene il piano master, le regole operative, lo snapshot di partenza e 47 ticket esecutivi PG-001–PG-047.

Ogni ticket include una checklist A–Z, una sola branch autorizzata, test, gate e criteri di chiusura. Il punto di ingresso è [00_MASTER_PLAN.md](00_MASTER_PLAN.md).

Prima di assegnare un ticket verificare sempre il `main` aggiornato: alcuni interventi possono essere già stati completati e devono quindi essere chiusi con evidenza, non rieseguiti o duplicati.
