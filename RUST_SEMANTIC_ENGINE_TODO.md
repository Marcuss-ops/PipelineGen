## Current implementation limits

- `semantic-engine` currently grounds entities, identity mentions, temporal/numeric facts, facility facts (including anaphoric sentences and `di <place>` location), asserted relations, bullet candidates, numeric comparison proposals, explicit numbered lists (line-based and inline), Top 10 completeness and date-backed chronological groups. Script generation now gets summary, heavy-sentence, chapter and highlight products from the same worker batch; standalone Phrase Impact remains for compatibility/parity tests but is no longer wired in production. The legacy Scene Intelligence worker is default-off and remains explicitly available for shadow comparison; its retirement is open pending parity and observability evidence.
- Broader asserted-relation extraction beyond the current lexical marker set is not yet implemented or parity-certified. Quotes cover explicit paired double quotation marks only. Every retained visual entity now gets a grounded source-text search query, but synonym expansion, independently authored search variants, and corpus-level object recall/precision remain unmeasured. The extractor now excludes Italian `si` pronouns from visual candidates without allowing a noisy PRON tag to discard proper-name candidates; the OpenAI and song-title regression tests pass. Process groups work within and across scenes when each phase explicitly names the same grounded identity. Cross-scene comparison groups require matching explicit comparison entity sets; causal chains require successive asserted edges sharing an identity and increasing scene order. These lexical groups require positive, certain wording. The semantic cutover preserves Phrase Impact's chosen bullet instead of letting the first VisualNER candidate replace it. Legal/procedural facts are lexical and conservative: unlisted predicates are not inferred, a date is never carried over from a neighbouring sentence, and the outcome stays in `normalized_value` while `normalized_date` is used for ordering. Bullet candidate generation and its salience now live in one `semantic-core::bullets` implementation; Phrase Impact still adds embedding-based diversity on top (`select_diverse`), which is a deliberate second stage rather than a second candidate algorithm. Visual keywords still come from VisualNER's noun-phrase/POS extraction; the fallback stopword list only removes glued function-word fragments, it does not add a general object lexicon. Co-mentions remain distinct from asserted relations. Existing Phrase Impact and Scene Intelligence modules remain pending those migrations.
- Verb filtering is now model-based: without a UDPipe model the lexicon fallback still removes stopwords, but no suffix heuristic guesses a predicate. This is deliberate (the suffix tables were deleted); a deployment without models keeps the model-free entity behavior and must not expect Italian verb filtering.
